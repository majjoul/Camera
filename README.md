# 👶 Baby Monitor App (Centralized Admin System)

تطبيق مراقبة الطفل الذكي والمبني باستعمال **Flutter** مع نظام الاقتران السريع عبر الرمز (Pairing Code).

---

## 🌟 المميزات الرئيسية (Features)

* **نظام الأدمن الموحد:** التحكم الكامل وبث الفيديو المباشر إلى جوال الأم.
* **اقتران آمن وسهل:** استخدام رمز مكون من 6 أرقام للربط بين الجهازين بدون الحاجة لـ QR Code.
* **تحكم عن بُعد:** تشغيل كشاف الجهاز الآخر (Flashlight) وتفعيل الميكروفون للحدث مع الطفل.
* **توفير الطاقة:** وضع تعتيم الشاشة الآلي لجوال الكاميرا للحفاظ على البطارية.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

* **Framework:** Flutter
* **Video Streaming:** `flutter_webrtc`
* **Hardware Integration:** `camera` & `torch_light`

---

## 📱 شاشات التطبيق (Screens Setup)

1. **شاشة اختيار الدور:** اختيار العمل كـ (جوال الأم) أو (جوال الطفل).
2. **لوحة تحكم الأم:** عرض البث المباشر وأزرار التحكم بالصوت والإضاءة.
3. **شاشة الطفل:** إدخال رمز الاقتران وبدء إرسال البث.
